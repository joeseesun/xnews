## 四个互斥 brief

| 方向 | 气质与排版 | 布局与密度 | 签名交互 / 不做什么 |
| --- | --- | --- | --- |
| **A · 晨报主编台（推荐）** | 周末版 FT / 第一财经早报；暖纸白、墨黑，系统宋体标题 + 系统中文 UI | 极窄日刊目录；大头条 + 其余列表；报章式密度 | 日期章、类型色标；默认单栏改写，原文收在「查看原文」抽屉；不做收件箱或图片瀑布流 |
| B · 对照阅览室 | Kindle 式暖暗阅读；大字号中文系统栈 + 英文 Georgia | 无侧栏；极简时间线与双栏文章；低密度 | 对照 / 只看改写 / 只看原文；独立位置保留、段落锚点同步；媒体归原文栏；不做首页大头条 |
| C · 信号台 | Superhuman / Linear 式工具；冷灰与单一靛青，紧凑无衬线 | 来源轨 + 高密条目列表 + 即时预览三栏 | 点击不跳页、j/k、Enter 打开、已读淡化、来源筛选；不做杂志式编排 |
| D · 影像刊 | 摄影选刊 / Are.na 影像板；亮底高反差，巨字 + 真实媒体 | 无侧栏；大小不等的媒体卡网格；中低密度 | 封面轻微悬停、全屏阅读层、底部薄条 RSS / 关于；无媒体条目使用编辑式巨字，不造假图 |

**推荐 A 的理由：**主编判断最先可见，3 秒能定位今日头条；5–15 分钟扫读有主次，进入一篇后仍保留安静长文空间。最贴合「可信、内容优先的海外发现早报」，不是单纯更炫。

遮住颜色仍可辨：A 是纸面头条与目录，B 是两页对照，C 是三栏收件箱，D 是大小图卡。四者还分别在字体角色、亮暗/色彩、布局、密度、印刷报章 / 暖夜电子书 / 当代工作台 / 摄影选刊气质上分歧。

## 选择协议

- 默认拨盘：视觉冒险度 **6**、动效强度 **4**、信息密度 **6**；数值随拖动实时更新。动效拨盘也即时改变轻动效时长；另两项记录最终实现偏好，不把四个不同布局变成一套模板。
- 每个方向只有一颗 `.qmdp-pick-button`。按钮或键盘 1–4 先打开确认弹层，保留调整建议；确认后才 `sendSelection` → `POST /api/select`，携带 `{id,label,name,notes,dials,adjustments}`。
- 页面自管中性外壳、确认与回传；通过预览桥识别标记防止服务重复注入。网络失败保留输入并可重试；`file://` 明示不会自动回传，并提供完整可复制选择文本。
- 每个样机是 960 × 600 的独立作用域舞台（`.dir-a` … `.dir-d`）；桌面 2×2，移动单列。可「放大」后以原尺寸阅读，窄屏只在样机内部横向滚动。
- 服务使用 `--exit-on-select`，确认时写入同目录 `selection.json` 并打印 `QIAOMU_DESIGN_SELECTION::`。应由当前工作流继续监听该服务输出；未有用户选择，不进入 Phase 3。

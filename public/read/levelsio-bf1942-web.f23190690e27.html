乔木改写

Pieter Levels 说，他反编译了可能是自己最喜欢的游戏《Battlefield 1942》，把它放到网页上，并加入多人联机。可试玩的是免费 shareware demo，地址为 bf1942.pieter.com。

按他的介绍，这次比之前移植 Quake 和 DOOM 困难得多：后两者已有大量开源项目和前人的工作可用，而《Battlefield 1942》没有这样的基础。他说，之前没人做过这个移植，也没有可用的开源引擎；开发商不像 id Software 对 Quake 3 那样开放过引擎源码。

他在半年前试过一次，基本放弃了。这次使用 Opus 5.5，重新请它尝试把文件夹中的 BF1942 demo 移植到网页。Levels 坦言，虽然说是自己和 Claude Code 合作，大部分工作实际由 Claude Code 完成。

他列出的步骤包括：

  • 反汇编原始 x86 机器码，识别出约 57000 个 x86 函数。
  • 把每个 x86 函数翻译成 C 函数，例如将 mov eax, [esi+0x110] 转为 eax = READ32(esi + 0x110)。他也承认自己并不理解这些代码的含义。
  • 生成约 100000 行 C 代码。
  • 用 Emscripten 编译为 WebAssembly。
  • 将游戏使用的约 300 个 Windows 和 Direct3D 函数重写为 WebGL 2、OpenGL 对应实现，使其能在网页上运行。
  • 自行构建网络栈，通过 WebSocket 连接多人服务器。

Levels 说，他并不清楚 Claude 是怎么完成这些工作的，但结果似乎能运行。他邀请读者试玩，并到原帖反馈发现的问题。

Battlefield 1942 decompiled to the browser

I decompiled probably my favorite game ever: Battlefield 1942 and I put it on the web with multiplayer for you to play here:

👉 https://t.co/6C8H8KtSaU 👈

(It's the free shareware demo)

It was way harder than the other ports like Quake and DOOM I did because they already had lots of open source projects and work behind them

In case of Battlefield 1942 there was literally absolutely nothing to work on top of, nobody had ever ported it and there was no open source engine for it, nor did the makers ever open source it (like id Software did with Quake 3)

I tried it 6 months ago and essentiay gave up but I tried it today again with Opus 5.5 asking "can you try port the BF1942 demo in this folder to web"

So me and Claude Code (well let's be honest mostly Claude Code) did crazy shit today:

  • it disassembled the x86 raw machine code to find 57,000 x86 functions
  • it translated each x86 function into a C function (mov eax, [esi+0x110] becomes eax = READ32(esi + 0x110), I have no idea what any of this means btw)
  • it outputed 100,000 lines of C
  • it then compiled that to WebAsswmbly with Emscripten
  • there were 300x Windows and Direct3D functions used which we had to rewrite to WebGL 2 and OpenGL to work on the web
  • then we had to build our own network stack so it could connect to our multiplayer server via WebSockets

I have no idea how it did any of this but it did it and it seems to work! 😊

Come play and report any bugs here!

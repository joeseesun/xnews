Cursor：描述一下工具，Agent 就能建成可分享的线上 App

写代码已经不难了，难的是大半项目死在 localhost。Cursor 把托管、数据库和安全检查一并接上。

乔木改写

Cursor 这条更新很短，但戳中一个真实痛点：

Agent 让写代码变容易了，大半 App 还是死在 localhost。

现在你可以跟 Cloud Agent 说「给我做一个周新增仪表盘」「给团队做一个报 bug 的内部工具」，它会从零或现有仓库建出可运行的 Web App：托管、需要时自动开 Postgres、跑确定性和 Agent 两层安全检查，再给你一个可分享链接。

关键细节在文档里更清楚：

  • 生成不等于上线，必须你主动 Publish
  • 发布前有四道硬检查：别把密钥写进文件、别带凭据文件、不发布 .env、不发布 source map
  • 另有一次 AI 安全审阅；过不了会列出要修的点
  • 可见范围分邀请制、团队、公开；Teams / Enterprise 默认关掉公开分享

Rauch 很快跟了一句：Grok 和 Cursor 都能在这条链上 build、deploy、scale。产品叙事已经从「帮你写代码」，推进到「帮你把内部工具真正交出去」。

对做产品的人来说，下一步问题很具体：你团队里那些只活在本机的小工具，有多少其实只差一次「可分享」？

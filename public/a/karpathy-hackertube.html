Karpathy 周末两小时：用 Claude 从 4300 万条 HN 评论里筛出 6454 个值得看的视频

受够了 YouTube 推荐，他把二十年 Hacker News 评论扔给 Opus 5.5，做了个不登录也好用的 HackerTube。

2026年11月1日 · 周日 Andrej Karpathy AI coding · product · HN

Andrej Karpathy 又交了一份周末作业。

这次叫 HackerTube。起因很简单：他烦 YouTube 推荐。于是让 Claude 把 Hacker News 二十年、大约 4300 万条评论滤了一遍，留下会反复被推荐的 6454 个视频。他自己说，用 Opus 5.5 大概花了两小时，观感「显著更好」。

站点在 hackertube.org。几个设计选择挺对味：

  • 不登录也能用，状态留在浏览器本地
  • 缩略图取视频中间的一帧，不跟那种被 A/B 测到极致的封面卷
  • 评论分析的底层数据打包成 zip，你也可以丢给 Claude，做自己的版本
  • 还有 HackerTube Longs

过程也值得记一笔。他默认用 Claude Code 桌面端、Opus 5.5 Medium。自己动手的部分很少：去 Google Cloud 开 YouTube API key、起一台 VPS、买域名。机器起来之后，把 IP 丢给 Claude，让它更新、加固、部署、优化，整条链路基本交给模型。

他收尾那句很轻，但分量不轻：

很多原本要花几周甚至几个月的项目，现在早饭前就能 few-shot 出来。我们还没想到的，还有多少？

这不是又一个「AI 写了个玩具」的故事。它更像在提醒：当你真正把「找信号」这件事外包给模型，产品形态会跟着变。HN 评论里本来就埋着高质量推荐，只是以前没人愿意花两小时把矿挖干净。
